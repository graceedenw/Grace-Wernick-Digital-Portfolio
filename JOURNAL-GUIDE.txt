UPLOAD: Extract this ZIP. Upload the five website files to the root of your existing GitHub repository, replacing study-abroad.html. Keep all existing files. This guide does not need to be uploaded.

To add content, edit journal-data.js. Arrays start empty intentionally. Examples below are fictional schemas, not actual memories. Use unique IDs and commas between objects. Upload photo files to the repository and use their exact relative paths. Do not publish private location details in real time, identifiable photos without permission, or sensitive travel documents.

entries: [{id:'entry-1',chapter:1,title:'My title',date:'2027-05-01',time:'10:00',location:'London',weather:'Cloudy',temperatureC:12,mood:'Excited',text:'My journal text'}]
photos: [{id:'photo-1',file:'my-photo.jpg',caption:'My caption',location:'London',date:'2027-05-14',tags:['Food & Drinks','Daily Life'],chapters:[4,5],entryIds:['entry-1'],favorite:true}]
journeys: [{date:'2027-05-14',mode:'car',distance:10,unit:'mi',description:'Journey description'}]
visits: [{location:'London',date:'2027-05-14'}]
bucket: [{title:'My planned experience',done:false}]

Chapter numbers 1–10 match the website order. Journey modes: car, airplane, walk; other modes are supported. Units: mi or km. Enter each journey once. Temperature is Celsius, automatically converted to Fahrenheit. Dates use YYYY-MM-DD. Map pins represent approximate town centers, not confirmed venues. The map uses Leaflet and OpenStreetMap and requires internet access. The countdown uses UK midnight May 13, not a confirmed departure time. Days completed are calendar-based. The site is public and static; updates are made through GitHub, not through a private editor on the website.
