# Grace Wernick — Professional Portfolio

A responsive, static HTML/CSS/JavaScript portfolio starter designed for deployment on Vercel.

## Preview locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Create a GitHub repository and upload the contents of this folder.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the GitHub repository.
4. Leave the framework preset as **Other**. No build command or output directory is required for this static site.
5. Deploy.

## Personalize before publishing
Search the project for:
- `your.email@example.com` — replace with your preferred public contact email.
- `https://www.linkedin.com/` — replace with your LinkedIn profile URL.
- Add your resume PDF to this folder and name it `resume.pdf`.
- Replace the portfolio section descriptions with your actual assignments and projects.
- Add images or screenshots to the folder and insert them in `index.html` with captions.
- Review all text and remove any placeholder language before submitting.

The site intentionally does not invent work experience, skills, or completed projects. Add only accurate information and coursework you are comfortable sharing publicly.
